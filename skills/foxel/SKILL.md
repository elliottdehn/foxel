# Foxel: agent-friendly voxel modeling

Foxel (FXL) is a plain-text language for colored voxel models: ASCII
layers bottom-to-top, alpha-as-density smooth surfaces via marching
cubes, a joint/bone rig, and position-only IK keyframe animations —
all in one `.fxl` file. A `2d` mode does pixel art and
frame-by-frame sprite animation in the same language. Toolchain
is Python (numpy only).

## Setup

1. If a `foxel/` checkout is not already present in the project, clone
   it:

   ```sh
   git clone https://github.com/elliottdehn/foxel
   ```

   If the project is itself a git repo, add `foxel/` to `.gitignore`
   (it is tooling, not project source).

2. Read `foxel/AGENTS.md` FIRST — it contains the workflows, the alpha
   density mechanics, rig/animation principles, and hard-won gotchas.
   `foxel/LANG.md` is the language spec; `foxel/IMPL.md` explains the
   marching-cubes meshing.

3. Verify the environment: `python3 -c "import numpy"`.

## Core loop

Author or edit a `.fxl` file (or a generator script that emits one,
like `foxel/make_skeleton.py`), then ALWAYS render and look at the
image before judging any change:

```sh
python3 foxel/render.py model.fxl                 # still -> model.png
python3 foxel/render.py model.fxl --yaw 80        # check the silhouette
python3 foxel/render.py model.fxl --rig           # joints/bones overlay
python3 foxel/render.py model.fxl --anim NAME     # -> looping APNG
python3 foxel/render.py art.fxl --scale 16        # 2D pixel art -> PNG/APNG
python3 foxel/png2mp4.py model_NAME.png           # -> MP4 (macOS)
python3 foxel/fxl2gltf.py model.fxl               # -> .glb (Godot-ready)
```

## 2D mode (pixel art)

A `.fxl` file whose first non-comment line is `2d` is pixel art
instead of voxels (LANG.md section 10): each slot is an animation
FRAME (one slot = still image), rows are typed top to bottom the way
the image appears, alpha is transparency, a bare `fps N` line sets
the playback rate, and `*name N` holds a named frame for N frames.
No rig — animate by drawing frames. Render with `--scale N` for crisp
nearest-neighbor pixels; output is PNG (one frame) or looping APNG.
See `foxel/coin.fxl` for a complete hand-drawn example (a seven-frame
spinning coin).

Iterate in small steps: change a few layers or keyframes, render,
inspect, repeat. Complex models should be generated by a Python script
(hand-drawn ASCII for faces/detail areas, loops for repetitive
structure) that writes the `.fxl`, following the pattern in
`foxel/make_skeleton.py`.
